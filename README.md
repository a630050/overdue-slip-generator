# 借書逾期通知單產生器

把圖書館系統匯出的「**借書逾期清單**」Excel，一鍵變成**以班級為單位**的「逾期書籍催還通知單」，並自動從圖書館網站查出每本書的**排架號**與**金額**，直接列印或另存 PDF。

- 單一 HTML 檔，**免安裝、免伺服器、免帳號**，用 Chrome / Edge 開啟即可。
- 清冊檔案只在你的瀏覽器處理，**不會上傳到任何地方**。
- 版型參考常見的「逾期書籍催還通知單」：一班一張、依座號排序、逾期天數紅字、虛線分隔。

> 目前以**巨耀資訊 WEBPAC 館藏服務平台**（臺北市各國中小學圖書館 `eschool.tp.edu.tw/library/`）為對象，實測學校：臺北市中山區吉林國小。其他使用同一套系統的學校理論上相同，但尚未逐校測試。

---

## 一、成品長什麼樣子

每個班級一頁 A4，內容包含：

| 區塊 | 內容 |
|---|---|
| 頂部 | 粗橫線、置中標題「○○國小 圖書館 逾期書籍催還通知單」 |
| 資訊列 | 左：單位（班級）　右：列印時間 |
| 說明句 | 下列書籍已於 ○ 逾期，若已歸還書籍者，請與「圖書館」確認書籍是否已確實歸還。 |
| 表格 | 職稱/座號 姓名、館藏登錄號、書名、索書、排架、金額、借閱日期、應還日期、逾期天數 |

- 「座號」格式為 `23號（112345）`，括號內是讀者編號，下一行是姓名。
- 「索書」分兩行：分類號、著者號。
- 日期為 `115-09-21`（民國年-月-日），逾期天數為紅字。
- 同班人數多時自動跨頁，表頭每頁重複。

## 二、使用方式

### 0. 準備

- 瀏覽器：**Chrome 或 Edge**（電腦版）。
- 一份從圖書館系統匯出的「借書逾期清單」（`.xls` 或 `.xlsx`）。
- 學校圖書館的網址，例如：
  `https://eschool.tp.edu.tw/library/library.action?schNo=343608`
  （網址最後的 `schNo=數字` 是學校代碼，一定要有。）

### 1. 開啟工具

下載本專案的 `index.html`，**直接雙擊**用瀏覽器開啟即可（不需要架設網站）。

### 2. 上傳逾期清單

點「選擇 XLS / XLSX 檔」，或直接把檔案拖曳到頁面。上傳後會立刻產生通知單，上方顯示：

> 共 20 個班級、39 位學生、73 本逾期書（每班一張）。

此時**已經可以列印**，只是「排架」與「金額」兩欄是空白的。要補上這兩欄，請繼續下面的步驟。

### 3. 第一次使用：安裝「📚 查排架號」書籤（只需做一次）

頁面上方會出現橘色按鈕 **📚 查排架號**。

1. 先讓瀏覽器顯示「書籤列」（Chrome / Edge：按 `Ctrl + Shift + B`）。
2. 用滑鼠**按住橘色按鈕，拖曳到書籤列**後放開（注意是「拖曳」，不是點擊）。

> 書籤列拖不出來？按旁邊的「複製書籤程式碼」，然後在書籤列按右鍵 → 新增書籤，名稱隨意，**網址欄貼上剛複製的內容**即可。

為什麼需要書籤？瀏覽器的安全限制不允許一般網頁直接讀取別的網站的資料，但書籤程式是在圖書館網站「自己的頁面」裡執行，不受這個限制，所以不用安裝任何軟體就能查詢。

### 4. 查詢排架號與金額

1. 在「排架號查詢」欄位貼上學校圖書館網址（有 `schNo=數字`；下次會自動記住）。
2. 按 **查排架號**，瀏覽器會開啟圖書館網頁。
   - 若顯示「瀏覽器擋住了跳出視窗」，請允許本頁的跳出視窗後再按一次。
3. 在**剛開啟的圖書館網頁**上，點一下書籤列的 **📚 查排架號**。
4. 圖書館頁面右上角會出現藍色進度框：「查詢中 12 / 73，請勿關閉此視窗」。
   - 速度約每秒 1 本（73 本約 75 秒）。**查詢期間請不要關閉那個視窗。**
5. 完成後視窗會自動關閉，回到本工具，通知單已填入排架與金額，並顯示：

> 完成：找到 73 本、查無 0 本（已標示在通知單上）

### 5. 列印或另存 PDF

1. 按左上角 **列印**（或 `Ctrl + P`）。
2. 印表機選「另存為 PDF」，或直接選實體印表機。
3. 紙張 **A4**、縮放 **100%**。
4. 預設檔名會是 `逾期通知單_年月日時分秒.pdf`，例如 `逾期通知單_20260427134725.pdf`。

## 三、結果怎麼判讀

| 通知單上的顯示 | 意思 |
|---|---|
| 排架欄有數字（如 `8057`） | 在圖書館網站查到了 |
| 排架欄紅字「**查無**」 | 圖書館網站找不到這本書／這個登錄號，請人工確認 |
| 排架欄「—」 | 查到這本書，但館藏資料沒有填排架號 |
| 金額欄空白 | 網站上這本書沒有填定價，或定價不是新臺幣、無法確定，**工具不會亂填** |

- **金額是書的定價**（書目資料的「價格」欄），並非賠償金額。價格結尾的 `.0` 會去掉（`280.0` → `280`）。
- 可辨識的價格寫法：`280`、`280.0`、`NT$260`、`新臺幣380元`、`1,295`；外幣（如 `US$12`）會留空。

## 四、輸入檔案需求

清冊檔案的表頭列需要包含下列欄名（順序不拘，工具是依欄名尋找，不是依固定位置）：

`班級`、`座號`、`姓名`、`讀者編號`、`登錄號`、`索書號`、`書名`、`借閱日期`、`應還日期`、`逾期天數`

另外會讀取表頭上方的學校名稱與「列印日期」。清冊中途重複出現的表頭列（分頁造成）會自動略過。

## 五、常見問題

**Q：按「查排架號」後沒有開啟任何視窗？**
瀏覽器擋住了跳出視窗。允許後再按一次。

**Q：點了書籤沒有反應，或跳出「請先在催書單工具按查排架號」？**
書籤必須在「由工具開啟的那個圖書館視窗」裡點。不要自己另外開圖書館網頁；也不要在工具頁面上點書籤。

**Q：點書籤出現「這不是巨耀圖書館系統的頁面」？**
該頁面網址沒有 `schNo`，或不是圖書館系統頁面。請確認貼的網址含 `schNo=數字`。

**Q：學校電腦無法使用書籤／書籤被封鎖？**
有些學校的瀏覽器政策會封鎖 `javascript:` 書籤。此時無法使用自動查詢；工具本身仍可產生通知單（排架、金額欄留空，之後手寫補上）。

**Q：有幾本「查無」？**
書名很常見、有許多版本時偶爾會查不到，工具會多次嘗試不同關鍵字與頁數，仍找不到才標「查無」。

**Q：列印出來灰底表頭不見了？**
在列印對話框的「更多設定」勾選「**背景圖形**」。

**Q：資料會被送到哪裡？**
清冊只在你的瀏覽器處理。查詢時，只有「書名、索書號、登錄號」會在你的瀏覽器與學校自己的圖書館網站之間傳遞；**不含學生姓名、班級、讀者編號**，也不會送到其他任何伺服器。

## 六、運作原理（給開發者）

1. 工具用 [SheetJS](https://sheetjs.com/) 解析 Excel（已內嵌，離線可用）。
2. 按「查排架號」時，工具以 `window.open` 開啟圖書館網頁，並等待來自該視窗的 `postMessage`。
3. 使用者點書籤後，書籤程式在圖書館網頁（同網域）內：
   - `POST /library/findInfo.action`：以書名搜尋，取得書的內部 `id`；
   - `POST /library/findItem.action`：以 `schNo` + `bookId` 取得該書每一冊的 `itemNo`（登錄號）與 `itemUnit`（館別 / 館藏地 / 排架號），以及書目的「ISBN／裝訂／價格」；
   - 以登錄號對應，把「排架號、價格」透過 `postMessage` 傳回工具。
4. 搜尋策略：完整書名 → 去掉標點／副書名 → 前 8 字等多組關鍵字，最多翻 3 頁（每頁 100 筆），並讓**索書號相符**的書優先檢查；同書名的多冊只查一次。4 個並行。
5. 安全：工具只接受「由自己開啟的那個視窗」且「網域符合所貼網址」的訊息，其餘一律忽略。

由於書籤程式碼就是工具內 `shelfBookmarklet()` 這個函式轉成的 `javascript:` 網址，修改查詢邏輯只要改這一個函式。
